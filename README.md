## The one-paragraph version

MSO indexed 4K → 12K URLs with no impression lift and ~28K stuck in *Crawled – currently not
indexed*. Root cause is not thin content: the catalogue runs on the Blue Ridge Knives
wholesale feed, so the product copy is duplicated across hundreds of higher-authority dealer
sites. The fix is **subtraction** — cut the submitted index from ~40K to ~1,500 quality URLs,
then convert the impressions already being earned into clicks via first-party review stars,
rewritten titles and on-page trust signals. $1,000/month is realistic for September;
$10,000/month is a November spike with paid support, or sustainable organic by Q2 2027.
